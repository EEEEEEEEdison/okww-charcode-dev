# 轴解析

## 输入

素材索引、候选文字轴、原视频和质量限制。

## 执行

1. 读取 [总入口](../../SKILL.md) 和 [evidence.md](../../harness/evidence.md)。
2. 按 [step1.md §2](../../harness/step1.md) 完成 G1。
3. 按 [baseline.md](../../harness/baseline.md) 收集角色代码基线。
4. 按 step1.md §3、§6 解释动作并处理问题。
5. 按 evidence.md §5 更新阶段交接。

## 输出与通过条件

- 所选文字轴、角色和共鸣链已确认。
- 动作意图、按法和跨动作依赖有可定位依据。
- 技能触发与切人类型已有判断或缺项编号。
- `baseline.md` 区分代码线索和教程证据。
- 问题按阻断项、待测项和非关键项分类。

缺少素材时，退回 [素材获取](../materials/SKILL.md)。
需要逐帧判断的问题交给 [时序建模](../timeline/SKILL.md)。
受问题影响的实现必须等待 G2 判定。

进入、退回或交给其他阶段时，按 [总入口的阶段切换](../../SKILL.md#阶段切换) 加载。
