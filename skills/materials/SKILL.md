# 素材获取

## 输入

用户的开发目标，以及文字轴、视频或来源位置。

## 执行

1. 读取 [总入口](../../SKILL.md) 的工作区要求。
2. 按 [evidence.md](../../harness/evidence.md) 确定待获取的信息。
3. 按 [step1.md §1](../../harness/step1.md) 收集素材。
4. 按 [timing.md §1](../../harness/timing.md) 保留时间证据。
5. 按 evidence.md §5 更新阶段交接。

## 输出与通过条件

- `media/info.md` 能定位原素材、所选片段和候选文字轴。
- 原视频、字幕或口播能覆盖影响操作的说明。
- 帧率、速度、剪辑及计时器可用性已有记录。
- 获取失败或低清造成的限制已有缺项记录。

关键说明缺失时，补采对应素材或向用户集中提问。
通过后进入 [轴解析](../rotation/SKILL.md)。

进入、退回或交给其他阶段时，按 [总入口的阶段切换](../../SKILL.md#阶段切换) 加载。
