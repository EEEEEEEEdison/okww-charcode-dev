# MCP 实测辅助

直接测试已有代码时，可从本 Skill 进入。
其他阶段宜读取本文件，不宜调用，以保留当前阶段。

## 输入

- 待测代码或已加载的版本，以及要判断的战斗行为。
- 目标场景、关卡、队伍和开场要求；已有信息仍适用时直接沿用。
- 本机运行目录和启动路径，见工作区的 `okww-harness.local.md`。
- 本轮测试范围、停止条件及已有授权。

不必先生成新代码、文字轴或整队时序。
已有日志、截图或评估结果能回答问题时，不必重新实测。

## 执行

1. 读取 [总入口](../../SKILL.md) 和 [实测操作指引](../../references/mcp-testing.md)。
2. 检查 ok-ww 运行时。未启动时，按指引启动并验证。
3. 调用当前 ok-ww MCP 的 `list_skills()`，按描述选择技能。
4. 用返回的 ID 调用 `get_skill(skill_id=...)`，读取正文及所需引用。
5. 按实测操作指引启动游戏、导航并选队，先停在未开战的可见队伍界面。
6. 按实测操作指引 §4 核对代码、队伍和开场条件，再调用会开战的恢复函数或内置技能。
7. 读取返回路径中的结果，按 [结果利用](../../references/mcp-testing.md#6-结果利用与收尾) 回答待测问题。

## 内置技能如何选

按 `list_skills()` 的当前结果选用，不得依赖固定清单。
以下名称仅供匹配用途；未返回时不得假定存在。

| 当前任务 | 查找的内置指引 |
|---|---|
| 使用框架、写薄 Task 或核对 API | 开发、任务编写或测试指引，例如 `develop` |
| 修改已注册任务后运行 | 任务重载指引，例如 `reload-tasks` |
| 测量当前队伍表现 | 队伍评估指引，例如 `evaluate-team` |
| 根据证据修改并比较候选 | 队伍改进指引，例如 `improve-team` |

本地引用的其他 Skill 可按返回路径读取。
不得把上游文件名当作宿主已注册的 Skill 名调用。
内置技能没有覆盖导航或特定行为判据时，按实测操作指引补薄 Task。
不得复制内置战斗逻辑或另写同义评估执行器。

## 使用边界

- MCP 不可用时，记录缺口；不得把连接配置教程加入本流程。
- MCP 连接可用不表示已获游戏操作授权。沿用已有授权，不重复审批。
- 启动、重启、进入挑战及记录覆盖的边界见实测操作指引。
- 只测试时，不得擅自修改角色逻辑、配装或战斗配置。
- 内置指引与当前源码不符时，按 [rules.md 0-1](../../rules.md#基线) 核对差异。
- 外来工坊代码的运行边界沿用 [evidence.md](../../harness/evidence.md)。

## 输出与通过条件

- 使用的内置技能 ID、代码版本、测试条件和证据路径可复查。
- 已回答待测问题，或明确记录阻断原因和未验证项。
- 启动成功、进入场景、代码执行成功和战斗行为通过分别判定。
- 测试停止后，活动任务与本轮诊断状态已按指引清理。

证据交给 [实测迭代](../iteration/SKILL.md) 分析。
需要改代码时进入 [代码实现](../implementation/SKILL.md)。
打包与静态检查仍由 [验证交付](../delivery/SKILL.md) 负责。
