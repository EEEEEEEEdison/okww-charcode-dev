# 实测迭代

## 输入

以下任一种输入：

- 待测代码与可判断成败的测试目标。
- 可定位到代码版本的日志或录屏。

测试或分析涉及模型时，才需要该版模型。
只测指定行为时，按本轮成败判据交付，不套用整队验收。
不得由局部测试通过推断整队实测完成。

## 执行

1. 读取 [总入口](../../SKILL.md) 和 [iterate.md](../../guides/iterate.md)。
2. 按 [evidence.md](../../guides/evidence.md) 核对运行条件与证据。
3. 已有证据时，先检查能否回答测试目标；能回答时不必重跑。
4. 需要采证或直接测试时，读取 [MCP Skill](../mcp/SKILL.md)，按其流程自动实测并生成报告。
5. 读取 [日志 Skill](../logging/SKILL.md)，用 `wait` 行和 probe 行定位卡点。
6. 需要比较耗时时，按 [timing.md](../../guides/timing.md) 核对口径及差值。
7. 解释偏差，按根因选择退回阶段。
8. 按 iterate.md §5–6 更新案例证据和验收状态。
   用户授权自主迭代时，按 iterate.md §4.1 的上限重复第 4–8 步。
9. 本轮得到可入卡的新结论，或与现有卡冲突的已验证证据时，进入 [知识提议](../proposal/SKILL.md)。

## 输出与通过条件

- 记录实际测试条件、测试证据和未验证项。
- 未运行的测试不得记为通过。
- 测试范围内的动作、触发、切人和耗时有证据或明确缺项。
- 涉及耗时比较时，本段差值与累计差值已分别记录。
- 根因结论区分观测、解释和待验证假设。
- 产生新版本时，改动目标和验证办法可复查。
- 已查清问题的 probe 行在新版本删除。
- 完成声明满足 iterate.md §6；缺视频时写明验证限制。

对照所需的来源缺失或片段不可读时，退回 [素材获取](../materials/SKILL.md)。
意图错误退回 [轴解析](../rotation/SKILL.md)。
测量或模型错误退回 [时序建模](../timeline/SKILL.md)。
实现错误退回 [代码实现](../implementation/SKILL.md)。
复验与打包交给 [验证交付](../delivery/SKILL.md)。

进入、退回或交给其他阶段时，按 [总入口的阶段切换](../../SKILL.md#阶段切换) 加载。
