# 角色语义卡

一张卡记录一个角色在某个共鸣链下的出招知识和补充说明，供步骤 1 判断按法、步骤 2 生成代码时使用。按共鸣链分卡，是因为不同共鸣链下技能表现不同；卡的内容不只是共鸣链效果。

## 规则

- **粒度**：一个角色的一个共鸣链一张卡，文件名为 `<类名>_C<共鸣链>.md`，例如 `Cantarella_C0.md`。
- **入卡前先问用户**：只有用户同意的条目才能写进卡里。还没确认的候选结论放在案例的问题清单里，不写进卡。
- **候选来源**只有以下四种，不上网查 wiki：
  - 视频简介和评论；
  - 视频画面推断；
  - 用户提供的攻略；
  - 用户的回答。
- **只记角色本身的知识**：换一个轴也成立的才入卡；只和某个轴有关的不入卡。技能用描述性名称（如“强化普攻”“终结技能”），不带任何作者的轴记号（如【A】、红字、变色）。
- **用卡**：步骤 1 用作者共鸣链的卡来理解视频。作者和用户共鸣链不同时，受影响的步骤要问用户（step1.md §2）。

## 卡片模板

```markdown
# <中文名>（<类名>）<共鸣链> 链

## 技能与按法
- E：……（来源：<视频简介 BVxxxx / 画面推断 BVxxxx@12.3s / 用户攻略 / 用户回答>；用户确认 <日期>）

## 状态与识别
- ……

## 时序
- ……

## 补充说明（可选）
- 不直接决定按键、但有助于理解角色的知识，例如 buff 机制、伤害类型、常见出招顺序
```

每条都要写明来源和确认日期。条目被证伪时直接修改或删除，不保留"已废弃"标注。
